# Tests

Run `swift test` on macOS for package tests. Run the `Framewright-Package` and `FramewrightDemo` schemes on an iOS simulator to verify the iOS package and demo integration. The demo project is at `Examples/FramewrightDemo/FramewrightDemo.xcodeproj`. See [CI and delivery](../docs/continuous-integration.md) for the hosted matrix.

| Coverage | Tests and fixtures |
| --- | --- |
| Analytics and export | Event validation, summaries, bounded retention, ordered delivery, overflow, sink isolation, and v2/v3 compatibility. `FramewrightAnalyticsTests/Fixtures/schema-v2-session.json` is hand-assembled. `FramewrightAnalyticsTests/Fixtures/android-v0.1.1-session.json` was generated by the tagged Android codec. |
| AVPlayer and HLS | Item lifecycle, timing and counter semantics, stale callbacks, local playback and failure, and opt-in [controlled HLS playback](MediaFixtures/README.md). |
| Bandwidth | Access-log counter mapping and reset behavior, item replacement, and six estimator vectors from Android v0.1.1. |
| Codec and FairPlay | Known and malformed media, stale inspection results, optional HLS variant inventory, and typed FairPlay attempt and lifecycle hooks. |
| Storage, overlay and demo | Reopening and exporting committed events, retention-limit rejection, delivery completeness, diagnostics state, and the demo's session workflows. |

The controlled HLS tests skip unless the fixture URL is supplied. Their recipe covers generation, playback, and injected server faults. The [OpenSpec execution evidence](../openspec/changes/ios-quality-roadmap/execution-evidence.md) records observed results and open acceptance checks.
